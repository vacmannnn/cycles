# cycles
Библиотека для поиска циклов в ориентированном графе. Переводной экзамен, зима 25/26

## Особенности
- Работает с любыми типами вершин (`int`, `string` и т.д.), которые поддерживают сравнение (`comparable`).
- Используется обход в глубину (DFS) с раскраской вершин (белый/серый/черный), что обеспечивает сложность **O(V + E)**.

## Установка
```bash
go get github.com/vacmannnn/cycles
```

## Использование
```go
package main

import "github.com/vacmannnn/cycles"

func main() {
	// Создание графа (список смежности)
	g := cycles.Graph[string]{
		"A": {"B"},
		"B": {"C"},
		"C": {"A"}, // Есть цикл A->B->C->A
	}

	if g.HasCycle() {
		fmt.Println("Цикл обнаружен")
	}
}
```
